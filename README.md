### About me

Hi, I'm **Gustavo de Lima** — a Fullstack Developer focused on **backend systems**.  
I build and maintain REST APIs and microservices with **Python (FastAPI / Flask)**, **Docker**, and **Linux**, with strong experience in troubleshooting, production debugging, and infrastructure.

I moved from technical support and network analysis into software development, so I ship with both **code quality** and **operational stability** in mind.

---

### What I work on

- **APIs and automation** — REST services, internal integrations, and process automation with Python  
- **Containerized systems** — microservices on Linux with Docker, Nginx, and Redis  
- **Production reliability** — debugging, log analysis, and keeping services stable under real load
